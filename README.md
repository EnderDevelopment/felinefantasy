# FelineFantasy

FelineFantasy is a Minecraft plugin that brings a whimsical twist to gameplay with cat-themed abilities. Players can choose from various cat types, each with unique abilities, such as freezing enemies with a yarn ball, launching laser beams, or becoming invisible. The plugin features a GUI for cat selection, individual cooldowns for abilities, and configurable settings in the config.yml file.

## Install

1. Download the plugin JAR file from the [GitHub releases page](https://github.com/EnderDevelopment/FelineFantasy/releases).
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart the server to load the plugin.

## Use

1. Players can use the `/choosecat` command to open the cat selection GUI.
2. Select a cat from the GUI to choose your cat type.
3. Use the `/catsability 1` or `/catsability 2` command to activate your cat's abilities.
4. Operators can use the `/catsability clearcooldown` command to clear ability cooldowns.
